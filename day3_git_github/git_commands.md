git init
creates a new repository

git clone <link>
downloads existing repository locally from github

git status 
shows modified files, staged files and unchecked files

git add .
moves files to staging area

git commit -m "message"
saves snapshot of staged changes

git push origin main
uploads commits to repository

git pull origin main
downloads latest changes

git log
displays commmit history

git branch feature-login
creates branch

git checkout feature-login
switches branch

git merge feature-login
combines changes from another branch
